# نوا — پلتفرم تولید محتوا و مدیریت کسب‌وکار (نسخهٔ نمایشی)

«نوا» یک نمونه‌کار تعاملی و کاملاً فارسی/راست‌به‌چپ است: یک وب‌اپلیکیشن SaaS با ۱۳ ماژول، ویرایشگر مقالهٔ بلوکی، استودیوهای پرامپت‌سازی عکس و ویدیو، تقویم جلالی و ذخیره‌سازی محلی — بدون هیچ وابستگی به بیلد، سرور یا کلید API.

## اجرا

دو راه، هر دو بدون نصب:

1. **ساده‌ترین راه:** فایل `index.html` را دابل‌کلیک کنید (همهٔ اسکریپت‌ها کلاسیک‌اند و از `file://` هم اجرا می‌شوند).
2. **با سرور محلی** (پیشنهادی برای رفتار نزدیک‌تر به وب واقعی):

   ```bash
   # در همین پوشه
   python -m http.server 8642
   # سپس: http://127.0.0.1:8642/
   ```

فونت «وزیرمتن» از Google Fonts می‌آید؛ بدون اینترنت، فونت جایگزین سیستم استفاده می‌شود و همه‌چیز همچنان کار می‌کند.

## امکانات پیاده‌شده

- **پوستهٔ کامل:** منوی کناری گروه‌بندی‌شده با شمارنده‌های زنده، نوار بالا با جست‌وجوی سراسری (ماژول‌ها + مقاله‌ها)، وضعیت اتصال، تم روشن/تیره/سیستمی با حفظ انتخاب، کشوی منو در موبایل.
- **داشبورد:** شروع سریع، آمار واقعی از دادهٔ همین مرورگر با تفکیک «دادهٔ شما / دادهٔ نمونه»، پیش‌نویس‌های اخیر، چک‌لیست راه‌اندازی.
- **مرکز تولید محتوا:** سه مسیر مستقل مقاله/عکس/ویدیو + ابزارهای متنی (کپشن، ایمیل، توضیح محصول، متن تبلیغاتی).
- **ویرایشگر مقالهٔ بلوکی:** پاراگراف غنی (پررنگ/کج/لینک با نوار شناور)، H2/H3، فهرست ساده و شماره‌دار، نقل‌قول، تصویر با متن جایگزین، بلوک لینک؛ افزودن/حذف/تکثیر/جابه‌جایی؛ پیش‌نمایش؛ شمارش کلمه و زمان مطالعه؛ **ذخیرهٔ خودکار** با وضعیت زنده و **۱۰ نسخهٔ بازیابی**؛ فهرست مقاله‌ها؛ خروجی HTML آمادهٔ وردپرس؛ پشتیبان JSON با واردکردن مجدد.
- **تنظیمات نوشته:** نویسنده، دسته‌بندی، برچسب‌ها، چکیده، تصویر شاخص، نامک، عنوان سئو، توضیحات متا، کلمهٔ کلیدی، پیش‌نمایش نتیجهٔ جست‌وجو، **بررسی‌های سادهٔ ساختار با توضیح** (بدون امتیاز جعلی سئو)، تاریخ پیشنهادی انتشار.
- **دستیار نگارش:** نوع مقاله، زبان، لحن، مخاطب، هدف، حجم، نکات/منابع/واژگان ممنوع، پرسش‌های متداول و CTA → بریف + درج ساختار پیشنهادی (H2ها) در مقاله. جای مشخص برای تولید AI آینده با وضعیت «نیازمند اتصال».
- **استودیوی عکس:** ۸ سبک، نور/پالت/پس‌زمینه/ترکیب‌بندی، زاویه و لنز، نسبت‌های ۱:۱ تا ۳:۲ + ابعاد سفارشی با اعتبارسنجی ۶۴–۴۰۹۶، فضای متن، تصویر مرجع با اعتبارسنجی نوع/حجم و نقش مرجع، پرامپت منفی، آزادی خلاقیت، ۴ قالب آماده، پرامپت نهایی قابل ویرایش/کپی/دانلود/ذخیره. با انتخاب زبان انگلیسی، **محدودیت ترجمهٔ متن آزاد صادقانه اعلام می‌شود**.
- **استودیوی ویدیو:** متن‌به‌ویدیو/تصویر‌به‌ویدیو، مشخصات فنی، حرکت دوربین و انتقال، **شات‌بندی با زمان و پرامپت هر شات**، فریم شروع/پایان، موسیقی/افکت/گویندگی با تخمین مدت، زیرنویس، CTA، پرامپت منفی، ثبات سوژه/سبک، ۴ قالب آماده، و **بررسی شفاف سازگاری تنظیمات با سرویس نمونه**.
- **مولد هوشمند:** نقطهٔ شروع سریع برای هر ۷ نوع خروجی با پرش به ابزار تخصصی.
- **هویت برند:** نام، حوزه، مخاطب، لحن، ارزش‌ها، رنگ‌ها، واژگان ترجیحی و ادعاهای ممنوع — قابل استفاده در دستیار مقاله.
- **کتابخانه و تقویم:** جست‌وجو، فیلتر نوع/منبع، مشاهده/ویرایش/تکثیر/حذف/خروجی؛ **تقویم جلالی** با برنامهٔ محلی (بدون ادعای انتشار واقعی).
- **گفت‌وگوی زنده و تیمی و دیدگاه‌ها:** رابط تعاملی کامل با برچسب «ارسال محلی/شبیه‌سازی‌شده/آزمایشی» — ارسال محلی هرگز جای ارسال واقعی نمی‌نشیند.
- **شرکت‌ها/تیم‌ها/دامنه‌ها/کاربران:** CRUD کامل با اعتبارسنجی (ایمیل، دامنه، نامک) و تأیید حذف.
- **تنظیمات:** تم، نمایش/پنهان‌سازی دادهٔ نمونه، پاک‌سازی نمونه‌ها، خروجی/ورودی کامل JSON، پاک‌کردن داده‌های کاربر، سهمیهٔ ذخیره‌سازی، و صفحهٔ اتصال‌ها با توضیح شفاف «کلید فقط سمت سرور».

## صداقت عملکرد (تعهد طراحی)

- بدون اتصال API، هیچ تولید واقعی مقاله/عکس/ویدیو ادعا نمی‌شود؛ خروجی‌ها با برچسب «قالبی» مشخص‌اند.
- داده‌های نمونه (برچسب «نمونه») از داده‌های کاربر جدا هستند و از تنظیمات قابل پاک‌سازی‌اند.
- هیچ کلید API دریافت یا ذخیره نمی‌شود؛ نقشهٔ اتصال آینده: سرویس واسط + متغیر محیطی سمت سرور.
- دکمهٔ بی‌عمل وجود ندارد: هر کنش یا کار می‌کند یا وضعیت اتصال لازم را نشان می‌دهد.

## معماری

```
nova/
├── index.html            ← نقطهٔ ورود (اسکریپت‌ها کلاسیک؛ از file:// هم اجرا می‌شود)
├── css/  tokens، base، layout، components، views (تم با متغیرهای CSS)
├── js/
│   ├── core/   utils (جلالی، پاک‌سازی XSS، …) · icons · store (مقاوم) · theme · router · ui (اجزای مشترک) · builders (منطق خالص)
│   ├── data/   options (کاتالوگ‌ها) · seed (دادهٔ نمونه)
│   ├── views/  dashboard · content-center · article-list · article-editor · article-panel · photo · video · text-tools · generator · brand · library · chats · comments · org · settings
│   └── app.js  پوسته، مسیرها، جست‌وجو، راه‌اندازی
└── tests/run-tests.cjs   ← ۴۸ آزمون منطق (node tests/run-tests.cjs)
```

- **ذخیره‌سازی:** `localStorage` با پیشوند نسخه‌دار `nova.v1.*`؛ مقاوم در برابر دادهٔ خراب (پشتیبان‌گیری خودکار کلید خراب)، خطای سهمیه (پیام + وضعیت خطای ذخیرهٔ خودکار) و مرورگرهای بدون حافظه.
- **امنیت نمایش:** همهٔ محتوای کاربر با گریز HTML؛ متن غنی با پاک‌ساز سفیدفهرست (حذف اسکریپت/استایل/رویدادها و نشانی‌های ناامن)؛ خروجی HTML مقاله نیز پاک‌سازی‌شده است.
- **فضای نام:** فقط `window.Nova` — بدون تداخل با نام‌های رزرو مرورگر (در آزمون‌ها سنجیده شده).

## آزمون‌ها

```bash
node tests/run-tests.cjs
```

۴۸ آزمون شامل: درستی تقویم جلالی (رفت‌وبرگشت ۲۰۰۰ روز + نوروزها)، پاک‌ساز XSS، اعتبارسنجی‌ها، پرامپت‌سازهای عکس/ویدیو، بررسی‌های سئو، لایهٔ ذخیره‌سازی (خرابی/سهمیه/واردکردن)، شکل دادهٔ نمونه و بهداشت فضای نام.

## محدودیت‌های شناخته‌شده

- تولید واقعی محتوا، اتصال چت و انتشار وردپرس آگاهانه پیاده نشده‌اند (نیازمند سرویس سمت سرور) — وضعیتشان در رابط صریح است.
- جابه‌جایی بلوک‌ها با دکمه‌های بالا/پایین است (کشیدن‌ورهاکردن پیاده نشده).
- بررسی موبایل از طریق پنجرهٔ باریک مرورگر انجام شد؛ آزمون گستردهٔ روی دستگاه واقعی موبایل انجام نشده است.
